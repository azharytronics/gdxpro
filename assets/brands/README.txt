BRAND ASSET STRUCTURE

The website uses stable numbered brand slots so the manufacturer assigned to a slot can be changed later without renaming folders or changing page code.

01/ through 09/ = brand slots
Inside every slot:
  01-logo.png = active logo
  02-logo.png = reserved logo slot
  03-logo.png = reserved logo slot

Use PNG images and keep the filenames unchanged.
The website hides the reserved slots until a real image replaces the placeholder.
